# Modelo de demostración

`vrm-demo.js` contiene, codificado en base64, el modelo **VRM1_Constraint_Twist_Sample**
del repositorio oficial de la especificación VRM
(https://github.com/vrm-c/vrm-specification/tree/master/samples/VRM1_Constraint_Twist_Sample).
